# Contributing

> Contributions are accepted under the repository licences: `Apache-2.0` for
> code and `CC-BY-4.0` for skill text and documentation (see `LICENSE`,
> `LICENSE-CC-BY-4.0` and `NOTICE`).

## Before a change

```sh
uv sync
uv run pytest
uv run python scripts/validate.py
```

Keep every file public-safe (see `AGENTS.md`).

## Pull requests

Changes are proposed as draft pull requests. Nothing is merged without review.
Publication and deployment are separate, authorised steps.
