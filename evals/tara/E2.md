# E2 — Palbociclib coverage, annotation and CDKN2A lines

**Runs when:** the drug and cell-line tools are live (`get_drug_info`,
`list_cell_lines`; both are on the public tool contract). Expected route:
`search_conditions` for presence and doses, `get_drug_info` for targets and
approval, `list_cell_lines` plus `cell_line_metadata` driver annotations for
CDKN2A.

## Prompt

> Is Palbociclib in Tahoe-100M? At which doses? What are its annotated targets
> and approval status, and which panel lines carry a CDKN2A driver annotation?

## Expected tool sequence

1. `search_conditions(query="albociclib")` — find the exact label
   (`palbociclib`, lowercase) and use it verbatim.
2. A drug-annotation tool for targets, mechanism and approval.
3. A cell-line tool, filtered on the CDKN2A driver annotation.

## Hard criteria

- The exact label is reported as `palbociclib` and used verbatim.
- Doses reported as the three release doses.
- Targets, mechanism class and approval taken from the annotation tool, not
  guessed.
- The line list carries Cellosaurus id **and** name, with the count stated.

## Soft criteria

- Says that an annotation is not a measured dependency.

## Frozen values

Label, dose set, targets, approval and the line list — frozen in
[frozen-expected-0.3.x.md](frozen-expected-0.3.x.md).
