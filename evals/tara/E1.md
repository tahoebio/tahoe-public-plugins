# E1 — Trametinib MEK-pathway pharmacodynamics across the panel

**Runs when:** today (the live tools only).

## Prompt

> In Tahoe-100M, how does Trametinib at 5 µM change DUSP6, ETV4, ETV5 and SPRY4
> expression versus vehicle across the panel? Report per cell line.

## Expected tool sequence

1. `list_releases()` — pin the release.
2. `resolve_genes(symbols=["DUSP6", "ETV4", "ETV5", "SPRY4"])`.
3. `search_conditions(drug="Trametinib")` — the exact label, not the solvate
   (unless both are reported as distinct treatments).
4. `get_expression_slice(genes=[...], conditions=["Trametinib"],
   include_matched_controls=true)`.

## Hard criteria

- The contrast is **computed by the analyst** from the treated rows and the
  matched `is_control` rows (matched on gene, plate and cell line) and is
  labelled **descriptive**; no p-value is invented.
- Direction: all four MEK-pathway transcripts **decrease** under Trametinib in
  most lines.
- A per-line table with `n_cells` and the number of samples per arm.
- `cpm_log1p` is named as the measurement.

## Soft criteria (reported, not failing)

- Notes that the Trametinib solvate label is a **separate** treatment.
- Flags the immortalized normal line (hTERT-HPNE) when a pan-cancer reading is
  tempting.

Per-line Δ medians, frozen from one reference run against the live service

## Failure modes this prompt probes

- Under-retrieval: answering without calling the tools.
- Re-subtracting: treating the served absolute values as if already a contrast.
- Wrong control: pooling controls across plates or lines.
- Inventing a p-value for a descriptive contrast.
