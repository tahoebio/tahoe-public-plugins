# Security

## Reporting

Report a suspected vulnerability **privately** — do not open a public issue.

- **GitHub private vulnerability reporting** — open the repository's
  **Security** tab and choose **Report a vulnerability**.
- **Email** — if you cannot use GitHub, write to `tara@tahoebio.ai`.

## Scope

The service protects serving cost, scientific correctness and availability.
Only approved public dataset content is served. Retrieved content is treated as
data, never as instructions.
