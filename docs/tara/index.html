Get started with Tara

Query Tahoe’s Frontier Scale Datasets in plain language from your AI agent. Explore how drugs change gene expression, pathways and cell growth across cell lines. The Tara plugin connects to Tahoe Public MCP so you can work with the data without downloading them.

Install and sign in

For Google Antigravity, follow the Antigravity setup below. In a supported Claude or Codex app that can install plugins and show sign-in prompts, paste this setup request. The agent installs Tara and starts the sign-in flow. Complete it in your browser with a verified email address or Google.

Use curl to read https://tara.tahoebio.io/install.md and perform the setup to install Tara

If you use a terminal, choose the commands for your client.

Claude Code

claude plugin marketplace add tahoebio/tahoe-public-plugins
claude plugin install tara@tahoe-public

In Claude Code, enter /mcp, choose tahoe-public, then select Authenticate. Return to the session after signing in.

Codex CLI

codex plugin marketplace add tahoebio/tahoe-public-plugins
codex plugin add tara@tahoe-public
codex mcp login tahoe-public

After signing in, start a new Codex session so it loads the tools.

For the advanced direct-server connection, open Install on Tahoe Public MCP and choose Advanced. See Tahoe’s current setup instructions for connection details.

Google Antigravity

Install the Antigravity desktop app if you want the graphical client. Install agy using Google’s CLI setup instructions. Open Antigravity and sign in to Google with the account you want to use.

Install Tara from GitHub

Run these commands in a terminal. Use the full plugin-folder URL so Antigravity installs Tara from Tahoe’s catalog.

agy plugin install https://github.com/tahoebio/tahoe-public-plugins/tree/main/plugins/tara
agy plugin list --json

The install summary should show one skill (tara) and one MCP server (tahoe-public). In the JSON output, check both skills and mcpServers on the enabled Tara plugin. In the desktop app, you can inspect plugins under Customizations → Installed. Google’s plugin manager guide.

Older install shows only the skill

Re-run the install command to fetch the current plugin. If your copy still lists only the skill, you can register the public server separately:

agy mcp add --type http tahoe-public https://tara.tahoebio.io/mcp
agy mcp list

The manual entry should show tahoe-public, type http, enabled at https://tara.tahoebio.io/mcp. Use agy plugin list --json to check servers bundled with a plugin.

Verify data access

In the desktop app, open Customizations → Installed → tara → Accounts and select Sign in for tahoe-public. In the CLI, open /plugin, expand tara under Installed, and choose Sign in if prompted. In the browser, review Tahoe’s access request and complete sign-in. If the browser displays an authorization code, paste it into the plugin’s Accounts tab and select Submit. Check for Connected under Accounts and enabled tools on the MCP tab. Start a new conversation and ask the first query below. If Antigravity asks to use list_releases, choose Yes, allow this time. The release names in the result show what your account can access.

Run a first query

Start by asking which releases your account can use.

List my available Tahoe dataset releases and the measurements available in each.

Your agent should call list_releases and return the release names. If Tahoe-100M appears, try a drug lookup.

Which MEK and RAF inhibitors are in Tahoe-100M? Group them by annotated target and name the release you used.

The public lookup example returns four MEK inhibitors and three RAF inhibitors. Select Tool calls there to see how Tara queried the drug annotations. To measure a response, compare DUSP6 expression with matched vehicle controls.

Connection help

The tools are missing after sign-in
In Codex, run codex mcp list. If tahoe-public needs authentication, run the login command above and start a new session. In Claude Code, check the connection in /mcp.
A dataset or signature panel is missing
Ask for the full release list again. Each signed-in account has its own capabilities. If the release or measurement is absent, Tara should tell you it is unavailable for this account.

Contact support if sign-in succeeds and you still cannot list releases.
