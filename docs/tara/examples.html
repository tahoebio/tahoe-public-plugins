Worked examples

Start with a biological question. Follow the measurement from the original prompt through to a result you can interpret.

To see the underlying queries, open the six interactive examples on Tahoe Public MCP. Select a question, then switch between Answer and Tool calls. Try the trametinib and DUSP6 example for a single melanoma line before comparing a different MEK inhibitor across lines below.

How does binimetinib change DUSP6 expression?

In Tahoe-100M, compare DUSP6 expression after binimetinib with matched vehicle. Show the direction and size of the change by cell line and dose. Flag missing comparisons.

Ask Tara to resolve DUSP6 and the drug conditions, then pair each treated cell line with vehicle controls from the same plate. The demo showed a broad decrease in DUSP6 expression. Inspect the individual lines and doses before describing how consistent that decrease was.

If Tara returns a table, check which expression measure it used. A difference in normalized expression and a DESeq2 log₂ fold change have different units. For a partial result, narrow to one line or dose before summarizing.

Do capivasertib and alpelisib lower PI3K/AKT output?

Compare capivasertib and alpelisib in Tahoe-100M at 5 µM. Which readout is validated for PI3K/AKT? How many cell lines score below vehicle for each drug? Repeat with the similarly named Hallmark set.

When discovery advertises the signatures panel, Tara can look up the validated readout with get_validated_signatures before requesting scores. The v02 panel selected PROGENY_PI3K_B for this process. A lower score is consistent with reduced transcriptional output.

The choice of readout changes the interpretation. For capivasertib, HALLMARK_PI3K_AKT_MTOR_SIGNALING scored above vehicle in 42 of the same 50 lines. That set failed validation for this process. Report it as an exploratory comparison and keep the validated score as the primary readout.

These are expression-based scores in cultured cell lines. A biochemical assay would be needed to measure kinase target engagement directly.

What if a process has no validated readout?

Does the Tahoe Signatures panel have a validated readout for apoptosis? Tell me what the registry found before scoring anything.

In v02 the tested apoptosis readout failed validation. Tara should report that outcome and stop before scoring. The absence of a validated score leaves the biological question open.

What does Emerald Bay measure?

In Emerald Bay, list the available cell lines and explain the released growth-response measurement. Include the dataset release and attribution.

First confirm that emerald-bay appears in your release list. Tara should keep that dataset selected when looking up cell lines and measurement definitions. The released value, growth_rate_released, describes five-day growth in vitro. Expression and growth can cover different samples, so ask which lines have both before comparing them.

See the dataset comparison for other measurements and how to cite Emerald Bay.
