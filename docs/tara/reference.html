Data reference

Tahoe-100M and Emerald Bay answer different questions. Check the signed-in release list, then choose a dataset and a measurement.

Dataset coverage

MeasurementTahoe-100MEmerald Bay
ExpressionTahoe-100MExpression and drug-versus-vehicle differential expression.Emerald BayRaw counts and pseudobulk CPM or log1p(CPM). Differential expression is unavailable.
PathwaysTahoe-100MDifferential pathway scores. Use a validated readout where the signatures panel supports the process.Emerald BayDifferential VISION scores already include the matched endpoint-control subtraction.
Cell responseTahoe-100MRelative depletion, cell-cycle effects, perturbation markers and distance from the vehicle centroid.Emerald BayReleased five-day in-vitro growth response.
AnnotationsTahoe-100MDrug targets, mechanism classes, doses and cell-line identities.Emerald BaySample, condition and cell-line identities. Preserve full labels for combination treatments.

CPM means counts per million across the whole measured expression profile. Keep missing measurements separate from measured zeros. Use get_guide for the selected dataset’s units, controls and coverage.

Full tool reference and dataset-specific behavior

Read a result

Release and population
Retain the dataset, release, measurement, cell lines, doses and control group with any result. For a signature score, also record the readout name, validation status and direction.
Inspect the request
Completed analysis results identify their release and record the request. For a custom question, Tara can run guarded read-only SQL against approved data. The result includes the exact SQL so you can inspect or repeat it.
Pending or incomplete queries
Some queries return a handle while they run. Tara can poll that query or cancel it on request. A truncated table is partial. Ask for a narrower slice or an aggregate with its denominator. See the current preview limits for per-account quotas, result size and handle lifetime.
Research interpretation
Drug annotations identify reported targets. Observed expression and growth describe responses in the measured cells. Patient treatment decisions are outside Tara’s research scope.

Privacy and support

Your client sends tool arguments to Tahoe’s remote service. Tahoe logs tool arguments, including SQL, and usage metadata. Keep credentials, patient information and confidential material out of queries. Scientific datasets are read-only. Sending feedback shares your text with Tahoe when you request it.

Read the privacy policy and terms of service. For help, open a GitHub issue or email tara@tahoebio.ai. Include the client, the release, and the error with sensitive details removed.

Cite the data

Tahoe-100M is released under CC0 1.0. Keep the data release in your methods so others can repeat the analysis. Tahoe-100M dataset card.

Emerald Bay is released under CC BY 4.0. Credit Tahoe Bio, link the dataset and license, record the revision, and describe any transformations you applied. Emerald Bay dataset card · CC BY 4.0.
